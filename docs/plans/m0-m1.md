# agmen M0 and M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold the workspace, settle the six risky unknowns with spikes (M0), including whether a small model can run the dispatcher that delegates work to bigger models, then ship the first usable slice (M1): authenticated identities exchanging typed, numbered, replayable messages, DMs and a swarm chat through Mosquitto and the hub, reachable from the `agmen` CLI and MCP server, deployed on the GroupDrive cluster.

**Architecture:** Clients publish only to `up/{identity_id}`; Mosquitto's dynamic security enforces that. The hub validates, dedupes, numbers each message per stream in one Postgres transaction, and a sweeper republishes to `feed` or `inbox/` and answers on `ack/`. agmend owns the human's login, mints child identities, keeps the SQLite outbox and replays gaps over HTTP; the CLI and MCP server talk only to agmend.

**Tech Stack:** Rust (edition 2024), tokio, axum, sqlx 0.9 (Postgres), rumqttc 0.25.1 (`v5`), rusqlite 0.41 (`bundled`), rmcp 3.7.0, keyring 4.2.0, schemars, ts-rs 12.0.1, Mosquitto 2.1, Postgres 16, Docker for integration tests, TypeScript for the Claude Code mod spike, Claude Code 2.1.310 headless for the dispatcher spike.

**Spec:** [../design.md](../design.md) and [../protocol.md](../protocol.md). Read both before Task 1.

## Review Focus

1. **Wrong client clock.** A laptop whose clock is 10 minutes off sends a CLAIM with `valid_until` that the hub judges by its own clock. Expected: the hub uses `hub_at` with a 120 s skew allowance and answers NACK `expired` only past that. Test: Task 10 `it_valid_until_uses_hub_clock`.
2. **Outbox drain after revocation.** An identity revoked while its outbox holds messages. Expected: each gets a final NACK `identity_revoked`, the outbox marks them `rejected`, retries stop. Test: Task 12 `outbox_stops_on_final_nack`.
3. **Duplicate deliveries after a hub crash.** The sweeper republishes a row it had already sent. Expected: readers drop it by `(stream, seq)` and never show it twice. Test: Task 12 `reader_drops_duplicate_seq`.
4. **Laptop asleep past session expiry.** The broker discarded the session, so queued QoS 1 messages are gone. Expected: on reconnect the client replays from its cursor over HTTP and fills every gap. Test: Task 16 `it_replay_after_session_expiry`.
5. **Long backlog.** A reader 10,000 messages behind. Expected: replay pages at 500, keeps order, ends at `state/head.feed_seq`. Test: Task 11 `it_replay_pages_in_order`.
6. **A dispatcher tries a human verb.** A dispatcher identity, or chat text steering it, posts RULING or PUSH_OK. Expected: final NACK `forbidden_verb` from the hub regardless of what the model decided. Tests: Task 10 `it_non_human_forbidden_verbs`, Task 7 `live_injection_never_delegates`.
