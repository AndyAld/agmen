# agmen M0 and M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold the workspace, settle the five risky unknowns with spikes (M0), then ship the first usable slice (M1): authenticated identities exchanging typed, numbered, replayable messages and DMs through Mosquitto and the hub, reachable from the `agmen` CLI and MCP server, deployed on the GroupDrive cluster.

**Architecture:** Clients publish only to `up/{identity_id}`; Mosquitto's dynamic security enforces that. The hub validates, dedupes, numbers each message per stream in one Postgres transaction, and a sweeper republishes to `feed` or `inbox/` and answers on `ack/`. agmend owns the human's login, mints child identities, keeps the SQLite outbox and replays gaps over HTTP; the CLI and MCP server talk only to agmend.

**Tech Stack:** Rust (edition 2024), tokio, axum, sqlx 0.9 (Postgres), rumqttc 0.25.1 (`v5`), rusqlite 0.41 (`bundled`), rmcp 3.7.0, keyring 4.2.0, schemars, ts-rs 12.0.1, Mosquitto 2.1, Postgres 16, Docker for integration tests, TypeScript for the Claude Code mod spike.

**Spec:** [../design.md](../design.md) and [../protocol.md](../protocol.md). Read both before Task 1.

## Global Constraints

- Edition 2024, `resolver = "3"`, `rust-version` and `rust-toolchain.toml` pinned to stable 1.99.1.
- `[workspace.lints.rust]`: `unsafe_code = "forbid"`, `missing_debug_implementations = "warn"`. `[workspace.lints.clippy]`: deny `unwrap_used`, `expect_used`, `panic`, `todo`, `unimplemented`, `unreachable`, `dbg_macro`. Members use `[lints] workspace = true`. `clippy.toml` sets `allow-unwrap-in-tests`, `allow-expect-in-tests`, `allow-panic-in-tests` to true.
- Libraries return one `thiserror` enum per API boundary; binaries use `anyhow` with `.context()` at every I/O and parse boundary; logging is `tracing`.
- Add crates with `cargo add` at task time (current versions), commit `Cargo.lock`, run CI with `--locked`.
- Gate (every task ends green): `cargo fmt --all --check`, `cargo clippy --workspace --all-targets --all-features -- -D warnings`, `cargo nextest run --workspace`, `cargo test --doc --workspace`, `RUSTDOCFLAGS="-D warnings" cargo doc --workspace --no-deps`, `cargo deny check`.
- Integration tests live in `tests/it_*.rs`, read `AGMEN_IT_MQTT`, `AGMEN_IT_PG`, `AGMEN_IT_HUB` and fail with a clear message when unset; run them with `cargo nextest run --workspace --profile it` after `docker compose -f deploy/dev/compose.yaml up -d`. Never mark them `#[ignore]` to get green.
- Ids are `[a-z0-9]{8,32}`, minted by the hub; never `/`, `+`, `#`. Body max 32,768 bytes; envelope max 64 KiB; QoS 1; topic prefix `agmen/v1/{tenant_id}/{project_id}/`.
- Container images use pinned tags (no `:latest`).
- Docs, comments, UI copy and commit messages: plain words, no em or en dashes. Commit messages are one short line; no AI attribution trailers.
- Secrets never land in command text, files, or commits; check `git diff --cached` before each commit.

## Review Focus

1. **Wrong client clock.** A laptop whose clock is 10 minutes off sends a CLAIM with `valid_until` that the hub judges by its own clock. Expected: the hub uses `hub_at` with a 120 s skew allowance and answers NACK `expired` only past that. Test: Task 9 `it_valid_until_uses_hub_clock`.
2. **Outbox drain after revocation.** An identity revoked while its outbox holds messages. Expected: each gets a final NACK `identity_revoked`, the outbox marks them `rejected`, retries stop. Test: Task 11 `outbox_stops_on_final_nack`.
3. **Duplicate deliveries after a hub crash.** The sweeper republishes a row it had already sent. Expected: readers drop it by `(stream, seq)` and never show it twice. Test: Task 11 `reader_drops_duplicate_seq`.
4. **Laptop asleep past session expiry.** The broker discarded the session, so queued QoS 1 messages are gone. Expected: on reconnect the client replays from its cursor over HTTP and fills every gap. Test: Task 15 `it_replay_after_session_expiry`.
5. **Long backlog.** A reader 10,000 messages behind. Expected: replay pages at 500, keeps order, ends at `state/head.feed_seq`. Test: Task 10 `it_replay_pages_in_order`.
